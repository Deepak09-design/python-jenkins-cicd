# Python Jenkins CI/CD Pipeline

## Project Overview

Automated Python application testing and execution
using Jenkins CI/CD.

## Technologies

- Python
- Jenkins
- Git
- GitHub
- Pytest
- Linux

## Pipeline Stages

1. Git Checkout
2. Python Version Check
3. Install Dependencies
4. Run Unit Tests
5. Run Application
6. Archive Artifacts

## Test Coverage

- Addition
- Subtraction
- Multiplication
- Division
- Division by Zero

## Expected Result

All five test cases should pass successfully.
